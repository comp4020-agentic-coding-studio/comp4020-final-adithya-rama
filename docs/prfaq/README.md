# Jet Skirmish PR/FAQ

A working-backwards document for Jet Skirmish, in four parts:

- [Press release](press-release.md): the one-page launch-day announcement.
- [Users](users.md): five people who might use the game, why, and in their words.
- [FAQ](faq.md): 100 questions from customers (50), engineers (30) and managers (20).
- [RICE](rice.md): twenty candidate features across UI, actions, art, elements,
  mechanics and user education, scored and sorted.

Answers describe the repository as of 28 October 2026. Where something is
implemented but unverified, or not done, the answer says so. Figures come from
the validation records listed at the end; where older documents disagree, the
latest dated record wins. The personas and their quotes are illustrative and
are **not** playtest results. No structured playtest has been run yet
([PLAYTEST.md](../PLAYTEST.md)).
