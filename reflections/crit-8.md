# Crit 8 reflection

My main breakthrough has been realising that good development is less about
building everything upfront and more about using agents deliberately, testing
what they produce, and correcting the process when something goes wrong. I want
to be the person thinking through the idea: brainstorming, deciding how the
system should behave, and giving the work a clear direction.

This has changed how I want to work as a developer. I want to focus more on
defining the problem, architecture, and quality criteria, while using AI as a
capable collaborator rather than writing every line myself. The agents can carry
out implementation, but I still need to decide whether what they produce
matches the game I have in mind.

For me, directing the work also means staying involved after giving the first
prompt. Testing and reviewing the result are part of that role. When something
is wrong, I want to correct both the immediate result and the instructions or
checks that allowed it. That is the way I want to develop my judgement while
using agents to build more than I could comfortably write alone.
